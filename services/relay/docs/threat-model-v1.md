# 릴레이 위협 모델 v1

대상은 단일 Node.js 릴레이와 PostgreSQL이다. 자체 암호 설계는 없다. TLS, SHA-256, OS CSPRNG만 쓰고 앱 수준 암호화나 E2EE를 제공한다고 주장하지 않는다.

## 보호 대상

- 토큰: QR, 차량, 폰 bearer
- 물품 초안: 이름(사용자 입력 문자열이라 개인정보가 들어갈 수 있음), 치수, 취급조건
- 사진: 별도 동의가 있을 때만
- 차량 scene: 릴레이에 없음. 릴레이가 손상돼도 scene을 쓸 경로가 없다

## 위협과 대응

| 위협 | 대응 | 남는 위험 |
|---|---|---|
| **휴대폰 분실** | 차량에서 revoke. 토큰은 비연장 24시간 뒤 자동 실효 | 해제 전까지 습득자는 초안을 보낼 수 있으나 차량 사용자 수락이 필요하다. 폰 로컬 outbox 삭제는 phone-web 안내 책임 |
| **차량 접근권 상실** | 폰에서 revoke | 양쪽 모두 불가하면 최대 24시간 유효 |
| **QR 엿보기/선점** | 5분, 일회 소비, 동시 claim 1건만 성공 | 선점되면 정상 폰은 `CONSUMED`를 받는다. 사용자는 해제 후 새 QR을 만들어야 한다 |
| **URL·리퍼러·로그로 토큰 유출** | fragment 전달, URL bearer 거부, `Referrer-Policy: no-referrer`, allowlist 로거 | 프록시·브라우저 확장은 범위 밖 |
| **토큰 추측** | 256비트, 미상 토큰 균일 401, 실패 횟수 제한 | 없음에 가깝다 |
| **DB 유출** | 토큰은 digest만 저장 | 활성 초안과 사진은 평문이다 |
| **TLS 종단·DB 관리자** | 최소 권한 role, TTL 삭제 | **이들은 내용을 볼 수 있다.** E2EE가 아니다 |
| **재전송·재생** | 유일 제약, 내용 hash, 자격 유효 동안 tombstone, 자격 만료 뒤 전면 401 | 없음 (프로토콜 범위) |
| **임의 사진·메타데이터** | MIME+magic, JPEG 전체 marker·scan 및 WebP 전체 청크 allowlist, 크기·해상도 상한, 파일명 필드 없음 | 픽셀과 허용된 ICC 영역 안의 내용은 검사하지 않는다. 구조 검사는 디코더 취약점 방어가 아니며 차량 디코딩 측의 방어가 필요하다 |
| **남용·자원 고갈** | 스트리밍 상한, 본문 읽기 전 자격 확인, pairing당 초안·바이트 상한, 전역 active pairing 상한, 메모리 속도 제한 | 제한 카운터는 프로세스별이며 재시작 시 초기화된다. 리버스 프록시 뒤에서는 주소가 하나로 보인다 (`X-Forwarded-For` 미신뢰). 공개 운영 전 재검토 필요 |
| **scene 변조** | scene·차량 제어 경로 없음, Envelope 거부, 차량 수락 필요 | 악성 초안의 판별은 차량 검증 책임 |
| **권한 상승** | runtime role은 DML만, 비superuser. DDL·설정 변경 실제 거부 확인 | 없음 (로컬 시험 범위) |

## 개인정보 최소화

- 저장: 물품 초안(활성 상태만), 사진(동의 시, 활성 상태만), 동의 버전, ack, 시각.
- 저장하지 않음: IP, User-Agent, 계정, 이름·이메일, 원본 파일명, 평문 토큰.
- 삭제 시점: 종료·해제 즉시 내용과 사진 삭제. 만료 초안은 조회에서 즉시 제외되고 cleanup에서 삭제. ack는 24시간, 최소 키·hash tombstone은 자격 만료 후 ack가 없어지면 삭제.
- **논리 삭제 한계**: PostgreSQL 삭제는 파일에서 즉시 지워지지 않는다. vacuum 전 dead tuple과 WAL, 백업에는 남을 수 있다. 시험에서 확인한 것은 평문 토큰이 데이터 디렉터리에 없다는 점뿐이며, 삭제된 물품 내용의 물리 소거는 확인하지 않았다.

## 전송 보안

TLS가 기본이다. 평문은 `RELAY_DEMO_LOCAL=1`과 loopback 주소가 함께일 때만 기동한다. 그 외에는 프로세스가 기동을 거부한다. 원격 DB는 `sslmode=verify-full`을 요구한다.

## 공개 운영 전 필수 게이트 (현재 not_run)

1. 공인 HTTPS와 호스팅: 미승인, 실행하지 않음.
2. 디스크·볼륨·백업 암호화: 관측하지 않음. 로컬 데이터 디렉터리는 OS 권한(0700)만 적용.
3. 개인정보 처리 고지와 TTL 실사용 검토: `pairing 5분 / draft 24시간 / ack 24시간`은 잠정값이다.
4. 프록시 뒤 속도 제한 재설계와 부하 시험.
5. 실폰 secure context, 실폰 QR 스캔, 실차: 이 담당 범위 밖이며 미시험.
